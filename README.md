# online-pizza-store
A Python desktop application for browsing pizzas, managing a shopping cart, and placing orders.
Built with Python, Tkinter and Pillow.

Features
-Browse pizza menu
-View pizza images and prices
-Select quantity
-Add items to cart
-Calculate order total
-Confirm orders
-Add new pizzas
-Delete pizzas
-CSV-based price storage

Tech Stack
Python
Tkinter
Pillow
CSV
